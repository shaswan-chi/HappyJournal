# 开发进度

已完成：

- 第一阶段：文字记录、IndexedDB 本机持久保存、多条日记与刷新读取。
- 第二阶段：标题、五种心情、摘要卡片、详情、编辑、删除确认和旧数据兼容。
- 第三阶段：每篇最多 3 张静态图片、预览移除、压缩、Blob 保存、封面、详情放大与编辑替换。
- 第四阶段：自由/日常/反思/时间四种记录方式；页签选择、动态字段、结构化保存、分节详情、编辑回填、动态时间行与排序，旧记录按自由记录兼容。

沿用原有暖色和首页网格，不引入框架。详细手动测试、字段结构和存储说明见 README.md。

回归测试：tests/templates.html、tests/diary-crud.html、tests/images.html，使用独立临时数据库，不修改正式日记。

后续功能需另行确认。本阶段不加入 AI、天气、定位、语音、搜索、标签、云端同步、登录、儿童模式、自动抠图、视频或动图。
