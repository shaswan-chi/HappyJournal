# 开心手帐 Happy Journal

已完成文字卡片首页、日期与文字表单，以及浏览器本地保存。页面视觉设计保持不变。

## 怎样打开

为了让浏览器始终找到同一份记录，请固定使用同一个浏览器、同一个浏览器用户和同一个网址，使用普通窗口（不要使用无痕窗口）。

1. 打开 PowerShell，输入以下两行（本机已经有 Python）：

   ```powershell
   cd D:\codex\Projects\HappyJournal
   python -m http.server 8765 --bind 127.0.0.1
   ```

2. 保持这个窗口开启，在 Edge 或 Chrome 中打开 `http://127.0.0.1:8765/`。
3. 点击“记录今天”，填写日期和文字，点击“保存回忆”。
4. 刷新页面，记录仍然保留；继续新增第二条，两条记录都会显示。
5. 关闭浏览器后，再用同一个浏览器打开上述网址，记录仍然保留。如果关闭了 PowerShell 或重启电脑，先重新运行上面的命令。

预览服务只提供网页文件，日记不发送给它。日记保存在浏览器的 IndexedDB 中。

不要混用 `localhost`、其他端口、直接双击 HTML 或不同浏览器：这些可能对应不同的存储空间。浏览器本地数据不是云端备份，清除网站数据或使用无痕模式会影响保留。旧版本仅在内存中的记录无法从已关闭或刷新的页面中恢复。

## 这次保存了什么

每条记录包含独立编号、选择的日记日期、完整文字，以及首次创建时间 `createdAt`（包括日期、时间和时区信息）。首页仍按日记日期从新到旧显示，同日按保存顺序从新到旧显示。鼠标停在卡片日期上，可查看创建时间；刷新不会改变这个时间。

保存时等待数据库事务完成后才显示成功，期间防止重复点击。保存失败会提示，并保留文字与日期供重试。读取失败不会把数据库清空，也不会把读取错误误认为没有记录。

## 文件职责

- `index.html`：首页、表单与本机保存提示。
- `styles/main.css`：原有视觉样式，本次未修改。
- `scripts/storage.js`：IndexedDB 数据库读写、创建时间和记录排序。
- `scripts/app.js`：启动读取、等待保存、错误提示与卡片显示。
- `tests/storage-failure.html`：只在测试页面的 iframe 内模拟写入事务中止，验证失败时保留输入；不清空已有数据库。运行预览服务后访问 `/tests/storage-failure.html`，查看 PASS / FAIL。

暂未加入图片、AI、天气、定位、语音、登录或云端同步。
