# 开心手帐 Happy Journal

已完成文字日记、本机 IndexedDB 保存，以及第二阶段的标题、心情、详情、编辑与删除。沿用原来的暖色配色和首页卡片网格，没有引入框架。

## 打开项目

在 PowerShell 中运行：

```powershell
cd D:\codex\Projects\HappyJournal
python -m http.server 8765 --bind 127.0.0.1
```

保持窗口开启，用固定浏览器的普通窗口访问 `http://127.0.0.1:8765/`。如果端口已被本项目占用，直接访问即可，不需要重复启动。

记录属于当前浏览器、浏览器用户和网站地址。不要混用不同浏览器、`localhost`、其他端口或双击 HTML 的打开方式。清除网站数据会清除日记；此版本没有云端同步或备份功能。

## 怎样使用和手动测试

1. 点击“记录今天”，填写标题、正文，选择开心、平静、难过、焦虑或期待，保存。标题可以不填，默认显示“今天的记录”；正文必填。
2. 首页卡片显示标题、创建日期与时间、心情、正文摘要（最多 100 个字符，视觉上最多三行）。按 F5 刷新，确认记录还在。
3. 点击卡片或用键盘 Tab 选中后按 Enter，查看完整标题、正文、心情、记录日期和创建时间。
4. 点击“编辑”，修改标题、正文和心情，点击“保存修改”。创建时间和原记录日期保持不变，额外记录最后修改时间。
5. 再按 F5，打开同一条记录，确认修改仍在。编辑未保存时点击“取消”，可继续填写或放弃修改。
6. 在详情点“删除”，先点“取消删除”，确认记录仍在。
7. 再点“删除”→“确认删除”，首页立即减少一条；按 F5，确认删除的日记没有恢复。正式日记删除后不能恢复，请使用测试内容验证。
8. 打开原先保存的旧记录：标题默认“今天的记录”、心情默认“平静”，正文和创建时间不变。旧记录也可以编辑和删除。

保存、修改、删除都等数据库事务完成后才提示成功。写入失败时保留表单输入；删除失败时保留详情和错误提示。读取失败显示错误及“重新读取”，不会清空数据库。

## 数据结构与兼容

数据库仍叫 `HappyJournal`，版本仍是 `1`，表仍是 `entries`，主键仍是自动生成的 `id`。只增加记录中的可选字段，不需要删除旧表或升级数据库版本。

| 字段 | 含义 | 本次变化 |
| --- | --- | --- |
| id | 每条记录的独立编号 | 保留 |
| date | 用户选择的日记日期，也是首页排序依据 | 保留，编辑不改变 |
| content | 完整正文 | 可编辑 |
| createdAt | 首次创建日期和时间（ISO 时间，显示时转为本地时间） | 原值保留 |
| title | 标题 | 新增，空白默认“今天的记录” |
| mood | 心情 | 新增，默认“平静” |
| updatedAt | 最后修改日期和时间 | 编辑成功时新增或更新 |

旧记录读取时，在显示用的对象上补充默认标题和心情，不会批量改写原数据库。只有主动编辑并保存后，才把新字段写进该条旧记录。未知心情同样按“平静”显示；若更早的记录没有创建时间，显示“旧记录未保存时间”，不编造时间。

## 文件职责

- `index.html`：表单、详情区域、删除二次确认和错误提示的位置。
- `styles/main.css`：保留原样式，补充标题、摘要、心情和详情的排版。
- `scripts/app.js`：切换首页/表单/详情、表单校验、编辑与删除交互、默认内容显示。
- `scripts/storage.js`：数据库新增、读取、更新、删除；事务完成后才确认成功；兼容旧字段。
- `tests/diary-crud.html`：独立临时数据库的完整回归测试，结束后清理测试库，不操作正式日记。
- `tests/storage-failure.html`：原有的保存失败检查页。
- `docs/steps.md`：开发进度。
