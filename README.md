# 开心手帐 Happy Journal

当前已完成“我的回忆”文字卡片首页和日期、文字表单：输入 → 保存 → 首页显示。

记录只保存在当前页面的内存里。刷新、关闭或重新打开页面后，记录消失。没有使用浏览器持久存储或云端服务。

## 怎样打开和测试（不用安装工具）

1. 在 Windows 文件资源管理器中打开 `D:\codex\Projects\HappyJournal`。
2. 双击 `index.html`。如果没有用浏览器打开，右键 → 打开方式 → Microsoft Edge 或 Chrome。
3. 点击“记录今天”或“写下第一篇回忆”。日期默认今天，可以自行改选。
4. 输入几句话，点击“保存回忆”。页面返回“我的回忆”，显示日期和完整文字卡片。
5. 再保存几篇不同日期的记录：日期较新的排在前面，同一天后保存的排在前面。
6. 尝试不填写文字、只输入空格或清空日期：不能保存。
7. 填写后点“取消”：可以继续填写，也可以放弃内容；不会增加记录。
8. 按 F5 刷新页面：所有测试记录清空，重新显示空状态。

文字中的换行会保留；长文字自动换行。缩小浏览器窗口后，卡片会改为单列。

## 文件职责

- `index.html`：首页、表单和提示文字。
- `styles/main.css`：暖色卡片、按钮和手机布局。
- `scripts/app.js`：切换页面、表单校验、取消确认和卡片显示。
- `scripts/storage.js`：用内存数组暂存记录并排序，刷新即清空。
- `docs/plan.md`：早期后续版本规划，不代表当前已实现的功能。
- `docs/steps.md`：开发阶段和当前完成情况。

本次未添加图片、编辑删除、云端、AI、天气、定位或语音功能。没有额外依赖，不需要 npm、构建或安装代码包。
