# 开心手帐 Happy Journal

已完成文字日记、本机持久保存、标题、心情、详情、编辑、删除，以及第三阶段的本地图片。保持原来的暖色配色和首页网格，不使用复杂框架。

## 打开项目

在 PowerShell 中运行：

```powershell
cd D:\codex\Projects\HappyJournal
python -m http.server 8765 --bind 127.0.0.1
```

保持窗口开启，用固定浏览器的普通窗口访问 `http://127.0.0.1:8765/`。若本项目已在此地址运行，直接访问即可。不要混用浏览器、浏览器用户、localhost、其他端口或双击 HTML 的打开方式，这些可能是不同的存储空间。

## 图片功能及手动测试

1. 点击“记录今天”，填写正文（必填）、标题（选填）和心情。
2. 点击“添加图片”，选择一张 JPG/JPEG、PNG 或 WEBP 静态图片。每张原图不超过 5MB，每篇最多 3 张。预览会在处理完后显示；可点击“移除图片”后再选择。
3. 保存，首页第一张图片作为封面；按 F5，确认封面还在。
4. 新建另一篇，选择 3 张图片并保存。点击卡片进入详情，确认全部图片可见。
5. 点击任意图片查看完整大图；点击“关闭图片”或按 Esc 关闭。
6. 点击“编辑”，移除一张旧图、添加一张新图并“保存修改”。刷新后检查图片和顺序。只移除尚未保存时，数据库还没有改变；取消并放弃编辑会保留原图。
7. 在详情点击“删除”，先验证取消不会删除，再用测试日记确认删除。刷新后记录与图片均不应恢复。
8. 检查旧版无图记录，仍应显示文字卡片，详情和编辑均正常。
9. 用超过 5MB、损坏或不支持的文件测试错误提示；有问题的图片不会添加，但有效图片与正文仍能保存。
10. 关闭浏览器，再在相同浏览器、相同网址打开确认。若关闭了本地服务，先重新运行上面的命令。

## 图片具体存在哪里

数据库仍叫 `HappyJournal`，版本仍为 `1`，表仍为 `entries`。每篇日记继续包含 `id`、`date`、`title`、`mood`、`content`、`createdAt` 和可选的 `updatedAt`，本次新增可选的 `images` 数组：

```text
images: [
  {
    id: 图片编号,
    name: 原文件名,
    blob: 缩小压缩后的完整图片文件数据,
    thumbnail: 小尺寸缩略图文件数据,
    width: 保存图片的宽度,
    height: 保存图片的高度
  }
]
```

Blob 可以理解为浏览器直接保存的一份文件数据。图片与正文在同一条日记、同一个数据库事务中保存，不写进项目 assets 文件夹，也不上传到服务器。

刷新后，从 IndexedDB 重新取出 Blob，生成本次显示用的临时地址。因此保留的是图片本身，不是会失效的 blob URL。编辑删除图片会替换该条记录的数组；删除整篇日记会一起删除内嵌图片及缩略图，没有独立图片表或遗留的引用文件。

旧记录没有 images 时当作空数组，不改写旧数据、不清空数据库。旧标题/心情依然采用默认值，编辑保持原创建时间。

## 怎样控制空间和内存

- 每篇最多 3 张，每张原图最多 5MB；超过 4000 万像素也拒绝处理。
- 自动将图片长边缩到最多 1600 像素并压缩，优先 WebP；不支持 WebP 编码的浏览器可回退为 PNG。原文件不会被修改。
- 每张保存的大图最多 2MB，额外缩略图长边最多 400 像素、文件最多 512KB；超出则提示并跳过。
- 不额外保存未经处理的原图，也不使用会膨胀体积的 base64 字符串。此版本不是原图备份工具。
- 逐张处理图片，首页只保留封面缩略图，图片延迟加载；进入详情才读取完整图片数据。
- 切换页面、移除图片、关闭大图时释放对应临时 URL；取消编辑后释放草稿图片引用。
- 数据库写入失败时不显示成功，保留文字和图片预览供重试。图片与正文写入同一个事务，不留下只保存一半的日记。

这些措施能减少占用，但大量日记仍可能填满浏览器空间，不能保证无限保存。空间不足时可先移除不需要的图片，或在确认后删除不需要的日记，再重试。浏览器本地存储不是云端备份，清除网站数据会清除日记；请不要用无痕窗口长期保存。

## 第四阶段：模板系统

新建时可以选择页签：自由记录、日常记录、反思记录、时间记录。标题、心情、日期和图片仍是共用字段；只显示当前模板的内容输入区。

- 自由记录：保留原有必填正文。
- 日常记录：发生的事情、开心的事、感谢的事、学到的事、明天计划，至少填写一项。
- 反思记录：困扰、当时情绪、事情经过、能控制/不能控制的事、下次做法、给未来自己的话，至少填写一项。
- 时间记录：每行一组时间和事件，可增加、移除或修改。至少一条完整记录；全空白行忽略，半填行提示补全。保存后按时间从早到晚排列，同一时间保留填写顺序。

在同一表单内切换模板会暂存各模板已填内容，切回来可以继续填写；保存只保存当前所选模板。没有保存的其他模板草稿不会写入数据库。

### 新增数据字段

数据库继续使用 `HappyJournal` / `entries` / 版本 `1`，不重建、不清空旧记录。每条日记增加：

| templateType | 名称 | templateData |
| --- | --- | --- |
| free | 自由记录 | 空对象，正文仍存在 content |
| daily | 日常记录 | happened、happy、grateful、learned、tomorrow 五个文本字段 |
| reflection | 反思记录 | concern、emotion、happened、canControl、cannotControl、nextTime、futureSelf 七个文本字段 |
| timeline | 时间记录 | rows 数组，每项是 time（HH:mm）和 event（事件文字） |

非自由模板保留独立的结构化字段，同时自动生成 content 文本用于首页摘要和兼容原有字段。详情读取 templateData，日常/反思分节显示，时间记录显示时间列表，不把 JSON 展示给用户。

缺少或无法识别 templateType 的旧记录按 free 处理，正文、图片和创建时间保持不变。读取不批量改写旧数据，用户编辑保存时才补充模板字段。

## 第五阶段：搜索、筛选与标签

首页新增轻量搜索框，点击“筛选回忆”才展开筛选面板。搜索、心情、模板、日期和点击标签得到的筛选会同时生效；当前条件与结果数量显示在卡片上方。

### 搜索与筛选规则

- 搜索标题、完整正文、日常/反思模板各字段、时间记录事件内容和标签，中文正常匹配，英文不区分大小写。
- 采用关键词连续匹配，例如“英语”可以找到“学习英语”。输入停顿约 150ms 后更新，减少连续输入时重复绘制页面。
- 清空搜索框只移除关键词条件，其他已选筛选继续生效；没有其他筛选时恢复全部记录。
- 日期按日记所选的 `date` 字段判断，不按最后编辑时间。最近 7 天包括今天及前 6 天；最近 30 天包括今天及前 29 天，不包含未来日期；今年是本地日历年 1 月 1 日至 12 月 31 日。
- 标签胶囊点击采用完整名称精确匹配；点击“取消标签筛选”仅移除标签条件。
- “清除筛选”清空搜索、心情、模板、日期和标签，并恢复“最新优先”。筛选条件本身不持久保存，刷新后恢复默认。
- 排序先按日记日期，再按原创建时间，最后用记录编号保证同时间记录稳定排列。“最早优先”反转顺序。
- 没有匹配结果显示“没有找到这段回忆”，不会删除或改写日记。

### 标签数据

每条记录新增 `tags: []`，仍存放在原 IndexedDB 数据库 `HappyJournal`、表 `entries`，数据库版本仍为 `1`。没有新建标签表，也不需要清空或迁移旧数据。

新建/编辑表单使用逗号、中文逗号或顿号分隔标签，例如 `学习、英语`。最多 5 个，每个最多 12 个 Unicode 字符；首尾空白会去除，完全重复的标签合并。首页显示可点击胶囊，详情显示完整标签；清空输入保存即可移除全部标签。保存失败保留输入，原记录不被部分修改。

旧记录没有 tags 时读取为空数组，可以照常打开、编辑和删除。编辑保存时再补齐标签字段，不批量重写旧数据库。

### 为什么搜索不需要反复访问数据库

打开页面时已读入日记的文字、模板字段、标签和封面缩略图。搜索直接在这份内存列表上比较；可搜索文字还会缓存起来。筛选只检查心情、模板、日期和标签，再排序显示。仅初次读取、重新读取、进入详情和保存/编辑/删除等操作需要数据库，打字、排序、清除筛选都不查询 IndexedDB。

## 第六阶段：回忆信息流

首页按“月份 → 记录日期 → 当天日记”排列，默认最新优先，仍可切换最早优先。日期使用写日记时选择的日期，卡片时间使用原始创建时间。同一天的日记共用日期分隔，年份只在月份标题显示。缺失日期的旧数据放在“日期未记录”下。

图片规则：1 张大图；2 张并排；3 张上方一张、下方两张。所有图片使用 contain 完整显示，宽高比不同会有纸张色留白，不拉伸或裁掉边缘。首页使用现有缩略图，完整图片仍可进入详情放大查看。

“随便看看过去”在全部已读入的日记中等概率随机选择一篇（不受当前筛选影响，也可能重复抽到同一篇）。0 篇时温暖提示，1 篇时直接打开。详情保留原来的编辑和删除操作。

性能：列表只保留最多三张缩略图，不持有完整大图；浏览器延迟加载和异步解码图片，屏幕外卡片延后绘制。滚动不访问 IndexedDB，搜索/筛选使用内存列表。返回首页保留原来的卡片与滚动位置；保存或删除后同步更新列表。其他标签页修改的数据需要刷新本页后显示。

数据库名称、版本、表结构与记录字段均不改变。旧记录继续兼容。新增 tests/feed.html 使用临时数据库测试纯文字、1/2/3 图、同日/跨日/跨月、随机 0/1/多条、搜索排序、详情与刷新；打开时会保留测试预览，关闭页面清理临时库。

手动验证：
1. 打开 http://127.0.0.1:8765/ 并刷新。
2. 分别创建纯文字、1 图、2 图、3 图日记，让两篇日期相同，另两篇分别设为前一天和上个月。
3. 检查月份/日期分隔及最新/最早排序，图片边缘是否完整显示。
4. 点击卡片进入详情，再返回，检查浏览位置；搜索文字和选择心情，确认分组随结果更新。
5. 点击“随便看看过去”，检查进入已有日记；刷新后再次检查图片和旧记录。
6. 缩窄浏览器窗口或在开发者工具中选择手机视口，检查无横向溢出。
